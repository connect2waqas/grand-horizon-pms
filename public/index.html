Full-Stack System Architecture & Case Study

Engineering Blueprint • Tech Stack Breakdown • Interactive Demos

Grand Horizon PMS is a production-grade, cloud-deployed Hotel Property Management System engineered with Python FastAPI, PostgreSQL (Supabase), and modern Vanilla ES6+ Web Components. Built to deliver sub-50ms query execution, offline-first PWA resilience, and strict ACID transaction integrity.

Frontend Client Layer
Vanilla JS ES6+ PWA Service Worker CSS Custom Tokens

Zero framework overhead (0kb React/Vue bloat) delivering instant First Contentful Paint (<0.4s). Implements Service Worker stale-while-revalidate offline caching, Web App Manifest for native desktop/mobile installs, and accessible semantic HTML5.

Backend REST API Layer
Python 3.14 FastAPI Pydantic v2 ASGI

Asynchronous Python REST API utilizing Pydantic v2 for strict type safety and schema validation. Features lifespan initialization, GZip compression middleware, CORS enforcement, and automated OpenAPI 3.1 / Swagger documentation.

Database & Transaction Layer
Supabase PostgreSQL SQLite (Dev) ACID Transactions

Dual database strategy: High-availability managed PostgreSQL on Supabase in production and zero-dependency SQLite for fast local development and CI testing. Strict relational constraints preventing double-booking race conditions with immutable audit logs.

Cloud & DevOps Delivery
Vercel Serverless Edge CDN GitHub CI/CD

Automated git-push deployment with Vercel Serverless Python functions, distributed Edge caching, and automated pre-flight health checks.
